# 眼睛为什么不停地动

*CNN 与生物视觉 · 第十篇*

读这一行字时，你不需要把头从左转到右，但眼睛在移动。即使盯住一个字，它也没有完全静止。

如果视觉只是把图片交给分类器，最自然的设计似乎是固定镜头、提高分辨率，尽量减少晃动。眼睛却把移动写进了工作方式：既用较大的扫视改变注视位置，也在注视期间保留细小运动。

原因不只有“省算力”。移动还会决定获得什么证据，以及空间细节怎样变成随时间变化的信号。

## 一、高分辨率是一块需要移动的区域

人的视野并不是一张各处同样精细的图片。中央凹提供较高的空间分辨能力；扫视把它转向不同位置，让细节依次进入适合辨认的区域。[Najemnik 与 Geisler，2005](https://doi.org/10.1038/nature03390)

可以试着盯住这行文字中的一个字，同时辨认远离注视点的小字。知道那里有文字，与看清每个笔画，是不同的能力。外围信息并未消失，只是不能在所有任务上替代中央细节。

从设计角度看，这是一种覆盖范围与精细处理之间的分配：先在较大范围获得信息，再把有限的精细取样能力放到有价值的位置。移动带来了覆盖，也付出了重新定位和等待的成本。

对机器而言，这未必总比一次处理整图划算。若任务要求同时监测多个快速变化的目标，逐处检查可能漏掉事件；若大部分画面与任务无关，局部精看才可能节约计算。优势取决于场景，不是“像眼睛”就天然更好。

还有一个容易漏算的成本：相机若已经读出整张高分辨率图，再裁剪局部，只减少了部分后续处理，并没有自动省掉完整采集的开销。生物启发要落实到具体环节，才知道节省发生在哪里。

## 二、下一眼应该看最显眼的地方吗

设想你需要区分两个模糊符号。它们上方都有一颗很亮的圆点，下方只有一笔不同：

```text
符号甲           符号乙
  ●                ●

  ─                │
```

如果亮点的位置与外观在两种符号中完全相同，那么无论把它看得多清楚，都不能据此区分甲乙。下方那一笔不那么醒目，却能消除当前的歧义。

因此，下一眼的价值不能只用亮度、对比度或“像不像目标”来衡量。还要问：看过那里以后，哪些可能性会被排除？

Najemnik 与 Geisler 让观察者在噪声背景中寻找目标，并根据不同视网膜位置的目标可见性建立理想搜索者。在这个受控任务里，人的搜索表现接近模型的最优表现。研究把眼动选择具体化为一个问题：根据已有证据和自己的视觉限制，下一次注视哪里最有利于找到目标。它并不证明日常每一次扫视都达到最优。[原论文](https://doi.org/10.1038/nature03390)

这与“先找一张显著性热图，再挑最亮处”有实质差别。一个地方是否值得再看，取决于任务、已经知道的内容，以及在那里还能获得多少新信息。

主动取样也因此需要记住某种状态。若每一眼都从零开始，模型可能反复检查同一块醒目的区域。它不一定要保存完整照片，但至少要保留足以指导下一步的证据。

代价同样明确：错误的早期判断可能把视线引向错误位置，让后续取样继续围着同一个猜测转。局部处理减少了计算，也增加了错过关键证据的机会。

## 三、小幅移动也能改变细节的编码

扫视解决“看哪里”，但注视期间的微小运动还有另一层作用。

想象一个感受器始终落在明暗条纹的同一处，它接收到的亮度可以近似不变。让条纹相对它缓慢移动，明暗交替经过这个位置，空间结构就转成了时间变化。运动没有凭空增加场景信息，却改变了信息进入传感器的形式。

Rucci 等人用随眼动调整显示的办法，减少注视间期本应发生的视网膜图像运动。在他们的噪声掩蔽条纹辨别实验中，正常的微小眼动有利于辨认高空间频率刺激，而低空间频率刺激没有同样的收益。实验支持了微小眼动参与精细信息编码的作用，不能据此推出“抖得越多看得越清”。[原论文，2007](https://doi.org/10.1038/nature05866)

但移动眼睛也制造了一个麻烦：视网膜上的运动，不等于外部物体的运动。

在一个头部固定、只考虑单一角度坐标的简化模型里：

```text
物体相对视线的位置 = 物体的方向角 − 眼睛的朝向角
相对运动速度       = 物体的角速度 − 眼睛转动的角速度
```

物体不动、眼睛向右转，图像就相对视线向左移；物体与眼睛以相同角速度向右运动，物体相对视线的位置反而不变。仅靠局部图像位移，无法唯一判断外部发生了什么。

第九篇的方向计算因此只是链路中的一部分。要把局部运动解释为世界中的运动，还需要结合眼动相关信息和场景关系。完整的神经机制不能由这条减法公式代替，但公式足以揭示：主动感知既创造新的观测，也需要处理自身行动造成的变化。

## 四、Transformer 的 attention 移动了什么

“注意力”这个名字，把几种不同的选择放在了一起。

| 操作 | 主要改变什么 |
| --- | --- |
| 移动眼睛 | 哪些外部区域落到哪些视网膜位置，进而改变采样条件 |
| 不移动视线而转移视觉注意 | 对所关注信息的处理优先级 |
| 标准 self-attention | 已有 token 之间的信息加权与汇总 |

视觉注意可以在没有相应扫视时转移；注意与眼动有关联，却不能把两者合并为同一个操作。[Posner，1980](https://doi.org/10.1080/00335558008248231)

标准 Transformer 的 attention 根据 query 与 key 的匹配计算权重，再汇总 value。输入的 token 已经存在，权重决定本次汇总更依赖哪些信息。这个运算本身不会把相机转向别处，也不会把没采到的笔画重新拍清楚。[Vaswani 等，2017](https://arxiv.org/abs/1706.03762)

权重小也不等于相应计算被省掉。在标准稠密 self-attention 中，低权重仍可能是在计算所有 token 对的匹配后才得到的；如果真要节约处理，需要另外设计稀疏连接、选择机制或输入采样策略。

离主动取样更近的一种做法，是让模型保留内部状态，再选择下一块要读取的区域。Mnih 等人的循环视觉注意模型就采用了逐次选择局部、在选定区域进行高分辨率处理的思路。这是一种具体的工程连接，也不是人眼机制的完整复制。[原论文，2014](https://arxiv.org/abs/1406.6247)

所以，比“Transformer 是不是更像人眼”更有用的比较是：它只是在重排已有证据，还是能决定接下来获取什么证据？两者可以组合，却解决着不同的问题。

回到电影院，即使放映给所有观众的是同一段画面，每个人注视的位置也会影响细节如何进入视觉系统。讨论银幕覆盖的视角时，不能只计算总共有多少像素，还要考虑哪些内容需要被精看，以及视线怎样在它们之间移动。

下一篇继续追问：如果已经看到了，也提取了特征，却仍然分不清，系统能否根据当前猜测重新检查证据？这才进入前馈、循环与反馈的区别。
