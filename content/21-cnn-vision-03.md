# 池化究竟丢掉了什么

CNN 与生物视觉 · 第三篇

一条亮线向右移动一个像素，还是那条亮线。可是经过最大池化，原本两个位置有响应，忽然只剩一个。

这与“池化让网络不怕平移”的常见解释，正好相反。

问题出在两个被捆在一起的决定：**如何汇总邻域，以及多久保留一个输出。** 前者决定忽略什么，后者决定采样密度。要理解池化的收益与代价，得先把它们拆开。

## 从复杂细胞借来的想法

Hubel 与 Wiesel 发现，一些复杂细胞对刺激方向很挑剔，却容许刺激在感受野内改变位置。这给了建模者一个思路：把偏好相同特征、感受野位置不同的单元汇总起来，让输出更关心“附近有没有”，少关心“准确在哪里”。[1](https://www.gatsby.ucl.ac.uk/teaching/courses/tn1-2020/additional/systems/JPhysiol-1962-Hubel-106-54.pdf)

最大值是实现这个想法的一种办法。邻域中只要一个探测器强烈响应，汇总结果就高。Riesenhuber 与 Poggio 的层级视觉模型采用了类似 MAX 的运算来构建容忍位置和尺度变化的表示。[2](https://www.nature.com/articles/nn1199_1019)

但从位置容忍度到 `max`，仍然是模型选择。生物实验没有给出一条“复杂细胞等于 2 × 2 最大池化”的程序。

最大值会具体丢掉什么？下面四种局部输入的结果完全一样：

```text
max(1, 0) = max(0, 1) = max(1, 1) = max(1, −5) = 1
```

最强响应还在，它的位置、出现次数和其他响应却无法从这个数恢复。“附近至少有一个”可能足够用于检测；数有几个、判断相互位置，就不够了。

## 在窗口里不变跨过窗口就变

把一维信号每两格分成一组，各取最大值：

```text
原输入   [0, 1] [1, 0] [0, 0] [0, 0]
输出        1      1      0      0

右移一格 [0, 0] [1, 1] [0, 0] [0, 0]
输出        0      1      0      0
```

没有任何亮点消失。只是两个亮点从分属两组，变成落入同一组，输出就少了一个非零值。

所谓局部容忍度，取决于特征有没有跨过分组边界。**窗口内的位置可以被忽略，窗口边界的位置却仍然重要。**

这一步可以拆成：先在每个位置做邻域最大值，再每隔两格保留一个结果。前一步若以步幅 1 滑动，在合适的边界条件下仍然平移等变；后一步改变了网格，原图移动一格相当于输出网格的半格，不能再用输出的整数平移描述。

因此，局部汇总不必缩小特征图，下采样也不必采用最大值。选择 `max` 与选择步幅 2，解决的是不同问题。

## 为什么先模糊再缩小有时更可靠

看另一条信号，亮暗逐格交替。每隔一格取样：

```text
输入       1 0 1 0 1 0 1 0
取偶数位置 1   1   1   1

右移一格   0 1 0 1 0 1 0 1
取偶数位置 0   0   0   0
```

同样的细条纹，只因与采样网格的对齐方式不同，缩小后就可能变成全亮或全暗。粗网格把细密变化误认成了另一种结构，这就是混叠的一个极端例子。

如果先用权重 [1, 2, 1]/4 平滑，循环边界下的这两条交替信号都会变成 0.5，再取样就不会跳变。

代价也一目了然：条纹被抹掉了。**抗混叠用主动舍弃无法可靠表示的细节，换取较稳定的粗尺度表示。** 它没有让低分辨率免费拥有高分辨率的信息。

*演示采用首尾相接的八格信号。切换输入、移动一格，比较直接取样、最大池化与平滑后取样。数值均为人工算例。*

这个三点滤波器能恰好消除上述逐格交替的分量，不代表它能消除所有混叠。最大值又是非线性运算，不能拿线性平均的性质直接套用。若先密集取最大值，再进行下采样，抗混叠滤波应作用于送去下采样的那张图。

Zhang 在 2019 年研究了这类处理与 CNN 的结合，在所测试的若干架构上改善了平移稳定性，并报告了 ImageNet 准确率收益。[3](https://proceedings.mlr.press/v97/zhang19a.html) 这给出了可验证的改进方向，但没有把“越模糊越好”变成定律。

## 换成更多卷积能不能保住准确率

先区分“换掉最大值”与“取消下采样”。

**换成步幅 2 的卷积**，仍然降低空间分辨率，只是把固定的汇总规则换成可学习的规则。All Convolutional Net 已经展示过，在其若干图像识别实验中，用增加步幅的卷积替换最大池化可以不损失准确率。[4](https://arxiv.org/html/1412.6806v3)

这说明池化不是必需品，却不能保证把 AlexNet 的某一层直接换掉就一定涨点。滤波器能学习，也不意味着训练目标一定会让它学成低通滤波器；步幅卷积仍然面对采样问题。

**改成步幅 1 的卷积，保持高分辨率**，则是另一笔账。宽高都不减半，空间位置就是原来的四倍。在通道数、核大小相同的情况下，后续同类卷积的乘加量大约也是四倍。

收益是让后续层继续接触细节。成本包括计算、激活存储，以及如何扩大所覆盖的输入范围。小物体或精确定位任务可能值得付这笔钱；若任务主要关心大尺度结构，保留所有位置未必划算。

还应区分空间尺寸与总信息量。下采样若伴随足够的通道扩展，可以把不同位置的信息搬进不同通道；可逆的空间到通道重排就是例子。真正不可恢复的，是把多个可能输入压成同一个表示、又没有旁路保留差异。

一旦 `max(1, 0)` 和 `max(0, 1)` 已变成同一个数，后面堆再多卷积，也无法只凭这个数知道原来的位置。网络可以根据其他线索猜测，但猜测不等于找回被删掉的证据。

## 从特征图回到银幕

电影里的细条纹与运动，也会遇到空间和时间采样问题。这是理解画面闪烁、细节变化的一条线索，但视觉系统并不是一串固定大小的池化窗口：上一章讨论的中央与周边差异，已经说明它的采样并不均匀。

讨论银幕尺寸和座位时，不能只问“看得够不够大”，还要问：细节以多大的视角落入眼睛，又落在什么视野位置。至于疲劳和损伤，需要另外的生理与临床证据，不能从混叠直接推断。

回到 CNN，池化的设计问题可以落在一句具体的话上：**这个任务允许我不再区分哪些输入？**

答案如果是“附近出现同一种特征，精确位置不重要”，汇总可能有益；答案如果是“这两点的间距就是我要测的量”，同样的汇总就可能提前删掉答案。

下一篇讨论层级：既然每一层都会选择保留什么，深网络为什么还能从局部边缘走向物体？我们又凭什么知道，它最后学到的是形状，而不只是纹理？

## 延伸阅读

1. Hubel & Wiesel（1962），[Receptive fields, binocular interaction and functional architecture in the cat’s visual cortex](https://www.gatsby.ucl.ac.uk/teaching/courses/tn1-2020/additional/systems/JPhysiol-1962-Hubel-106-54.pdf)。复杂细胞的方向选择性与位置容忍度。

4. Springenberg 等（2015），[Striving for Simplicity: The All Convolutional Net](https://arxiv.org/html/1412.6806v3)。用步幅卷积替换最大池化的实验。
