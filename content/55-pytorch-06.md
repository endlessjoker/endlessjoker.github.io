# 为什么学习率大了反而学不好

看得懂的 PyTorch · 第 6 讲

梯度给出的方向正确，参数仍可能越改越差。原因在于：梯度描述当前位置的变化率，而一次更新可能直接跨过最低点，落到更高的位置。

这个过程用一个参数就能算清。

## 最低点在 3 的损失

设模型只输出参数 `w`，正确答案为 3，损失为：

```text
L = (w − 3)²
梯度 = 2(w − 3)
```

从 `w=0` 开始，损失为 9，梯度为 −6。学习率记作 `lr`，更新公式是：

```text
w_new = w − lr × 2(w − 3)
```

不同学习率的第一步如下：

| 学习率 | 更新后的 w | 新损失 |
|---|---|---|
| 0.1 | 0.6 | 5.76 |
| 0.5 | 3 | 0 |
| 0.9 | 5.4 | 5.76 |
| 1.0 | 6 | 9 |
| 1.1 | 6.6 | 12.96 |

学习率 0.9 已跨过最低点，但离 3 比原来更近，所以损失仍然下降。到了 1.1，跨越幅度过大，新位置比起点离最低点更远。

**跨过最低点不一定有害，关键在于更新后距离是否缩小。**

## 连续更新会发生什么

```python
import torch

def run(lr, steps=4):
    w = torch.tensor(0., dtype=torch.float64, requires_grad=True)
    positions = [w.item()]

    for _ in range(steps):
        w.grad = None
        loss = (w - 3).square()
        loss.backward()
        with torch.no_grad():
            w -= lr * w.grad
        positions.append(w.item())

    with torch.no_grad():
        final_loss = (w - 3).square().item()
    return positions, final_loss

for lr in [0.1, 0.5, 0.9, 1.0, 1.1]:
    positions, loss = run(lr)
    print(lr, [round(v, 4) for v in positions], round(loss, 4))
```

每组位置包含起点和四次更新结果：

```text
0.1 [0.0, 0.6, 1.08, 1.464, 1.7712]     1.5099
0.5 [0.0, 3.0, 3.0, 3.0, 3.0]          0.0
0.9 [0.0, 5.4, 1.08, 4.536, 1.7712]    1.5099
1.0 [0.0, 6.0, 0.0, 6.0, 0.0]          9.0
1.1 [0.0, 6.6, -1.32, 8.184, -3.2208]  38.6984
```

0.1 从同一侧逐渐接近 3；0.9 在两侧交替接近；1.0 永远在 0 和 6 之间往返；1.1 则每次都离最低点更远。

其中 0.1 和 0.9 每一步的损失都相同。增大学习率并没有让它更快，只是改变了接近最低点的路径。

## 收敛条件可以直接算出来

令 `d = w − 3`，表示参数与最低点的有符号距离。将更新公式两边减去 3：

```text
d_new = (1 − 2lr) × d
```

每次更新都把距离乘以同一个数：

| 学习率 | 距离乘数 | 结果 |
|---|---|---|
| 0.1 | 0.8 | 距离缩小，保持同侧 |
| 0.5 | 0 | 一步到达最低点 |
| 0.9 | −0.8 | 距离缩小，换到另一侧 |
| 1.0 | −1 | 距离不变，换到另一侧 |
| 1.1 | −1.2 | 距离扩大，换到另一侧 |

从非最优位置出发，要让距离不断缩小，必须满足：

```text
|1 − 2lr| < 1
因此：0 < lr < 1
```

损失是距离的平方，所以每步损失乘以 `(1 − 2lr)²`。学习率 1.1 对应乘数 1.44，损失会以这个比例持续放大。

这个范围只适用于当前损失和普通梯度下降，不能直接套到其他模型。

## 换个输入尺度 范围就变了

把预测从 `w` 改成 `10w`，答案仍然是 3：

```text
预测 = 10w
损失 = (10w − 3)² = 100(w − 0.3)²
梯度 = 20(10w − 3)
```

最低点变成 `w=0.3`，损失曲线也更陡。令 `d=w−0.3`，更新后：

```text
d_new = (1 − 200lr) × d
收敛条件：0 < lr < 0.01
```

原本温和的 0.1，现在远超稳定范围。从零开始，第一步就会跳到 `w=6`，预测达到 60，损失从 9 升到 3249。

```python
for lr in [0.1, 0.005]:
    w = torch.tensor(0., dtype=torch.float64, requires_grad=True)
    loss = (10 * w - 3).square()
    loss.backward()

    with torch.no_grad():
        w -= lr * w.grad
        prediction = 10 * w
        loss_after = (prediction - 3).square()

    print(lr, round(w.item(), 4),
          round(prediction.item(), 4), round(loss_after.item(), 4))

# 学习率   w    预测    损失
# 0.1     6.0   60.0   3249.0
# 0.005   0.3    3.0      0.0
```

输入放大 10 倍，这个二次损失对权重的曲率放大 100 倍，稳定学习率上限相应缩小到原来的百分之一。

这也解释了为什么特征缩放会影响训练。面积、价格等数值的单位改变后，原来的学习率未必仍然合适。标准化有助于缓和特征尺度差异，但不能保证任意学习率都稳定。

## 回到三套房屋

第五讲使用学习率 0.005。保持数据、初始参数和更新规则不变，只修改学习率：

```python
X = torch.tensor([[6., 2.], [8., 3.], [10., 3.]], dtype=torch.float64)
y = torch.tensor([95., 110., 140.], dtype=torch.float64)

def train_houses(lr, steps=5):
    w = torch.tensor([10., 5.], dtype=torch.float64, requires_grad=True)
    b = torch.tensor(20., dtype=torch.float64, requires_grad=True)
    losses = [25.]

    for _ in range(steps):
        w.grad = None
        b.grad = None
        loss = ((X @ w + b - y) ** 2).mean()
        loss.backward()

        with torch.no_grad():
            w -= lr * w.grad
            b -= lr * b.grad
            after = ((X @ w + b - y) ** 2).mean()
        losses.append(after.item())

    return losses

for lr in [0.005, 0.01, 0.02, 0.05]:
    values = train_houses(lr)
    print(lr, [round(v, 4) for v in values])
```

所有组的初始损失均为 25，更新后的结果为：

| 学习率 | 第 1 步 | 第 2 步 | 第 5 步 |
|---|---|---|---|
| 0.005 | 22.5944 | 22.4232 | 22.3506 |
| 0.01 | 23.0441 | 22.5278 | 22.2493 |
| 0.02 | 32.5096 | 62.6732 | 2574.6483 |
| 0.05 | 129.4352 | 4536.3120 | 337211573.8008 |

0.01 第一步落后于 0.005，到第五步却稍好。只看第一次损失下降多少，无法判断后续速度。0.02 和 0.05 则已明显发散。

这个模型有三个参数，损失曲面在不同方向上的弯曲程度不同。同一个学习率在某些方向上移动缓慢，在另一些方向上却可能越界；不能靠一味增大学习率解决训练慢的问题。

## 怎样判断实际训练中的学习率

上面的实验固定数据、全批次求梯度，变化完全来自参数更新。真实的小批次训练每次可能看到不同样本，损失偶尔上升很正常，单次波动不足以判定发散。

比较学习率时，应固定初始参数、数据顺序和损失定义，观察一段训练中的趋势。持续、快速放大是明显的失稳信号；缓慢下降则还需检查特征尺度、梯度和模型能力。调小学习率能减小步幅，但学习率为零时，损失也会“很稳定”——参数根本没有学习。

学习率控制每次更新走多远。梯度只在当前位置提供方向，步幅必须与损失曲面的变化速度相配。
