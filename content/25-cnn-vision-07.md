# 脑机接口里的两个学习者

*CNN 与生物视觉 · 第七篇*

一个人用脑机接口控制光标。第一天，光标总是偏；几天后，操作顺畅了。

我们通常会说，模型越来越懂这个人了。但如果模型参数从头到尾没变呢？

那就要考虑另一个学习者：人正在适应模型。脑机接口从此不只是“信号输入，指令输出”。输出会被人看见，改变下一次尝试，也改变接下来输入模型的数据。

书中第八章和第十五章谈到反馈、适应与康复。最值得展开的，是这条回路带来的设计取舍：**系统既要纠正自己的错误，又要给使用者留下可以学会的规律。**

## 一、模型不更新，大脑也可能学会

Ganguly 与 Carmena 在猕猴实验中，把运动皮层的稳定记录接入固定解码器，让动物控制外部设备。随着熟练控制形成，研究者观察到了稳定的群体神经活动模式；改变解码器或参与解码的神经元集合，又可能扰乱控制。这说明在该实验条件下，固定映射可以成为神经系统学习与巩固的对象。[原论文，2009](https://doi.org/10.1371/journal.pbio.1000153)

这与离线分类有一个根本区别。离线模型拿到已经记录好的数据，换一个分类器，不会改变那段过去的记录。在线系统改变解码规则，使用者看到的后果也随之改变，之后的数据就可能不一样。

把回路展开，是这样的：

```text
人的当前策略 → 神经活动 → 解码器 → 光标运动
      ↑                            ↓
      └────── 看到结果，调整尝试 ──────┘
```

所以，一个模型在旧记录上预测得更准，不足以证明它会让人控制得更好。它还可能改变响应速度、输出幅度和可预测性。这些变化都会影响使用者接下来的操作。

这里的学习也不要求使用者能说清自己怎样调整了神经活动。关键在于，反馈能否帮助形成可重复的控制方式。

## 二、两边都改正，为什么反而越改越偏

设想光标向右偏了。使用者看见偏差，开始往左补偿；模型也检测到右偏，更新参数，给出向左的修正。两边各自都做了合理的事，合在一起却可能修正过头。

用一个刻意简化的模型，可以算清这种风险。假设人的控制偏置为 `p`，机器的偏置为 `q`，总误差是 `e = p + q`，目标误差为零。两边根据同一次误差同步更新：

```text
人的新偏置   = p − αe
机器的新偏置 = q − βe

下一次总误差 = (1 − α − β)e
```

若人的修正系数为 1.1，机器固定不动，每轮误差会乘以 −0.1：虽会左右交替，但幅度迅速缩小。反过来，只让机器以 1.1 修正，也一样。

可是两边同时使用 1.1，误差每轮就乘以 −1.2：方向来回翻转，幅度不断增大。各自单独稳定的更新，合起来失稳了。

| 人的修正系数 α | 机器的修正系数 β | 每轮误差乘以 | 结果 |
| --- | --- | --- | --- |
| 0.4 | 0 | 0.6 | 逐渐缩小 |
| 0.4 | 0.4 | 0.2 | 更快缩小 |
| 1.1 | 0 | −0.1 | 交替缩小 |
| 1.1 | 1.1 | −1.2 | 交替放大 |

这不是大脑学习率的实测公式。真实系统存在延迟、噪声和非线性，人也未必知道误差来源。这个例子只证明一件事：评价两套更新规则，不能只看它们各自是否有效，还要看同时运行时的结果。

由此得到的工程选择是限制更新幅度、安排不同的更新时间，或者在部分阶段固定映射，给另一方留下适应空间。哪种更合适，需要在线比较，不能从“自适应”三个字直接推出。

## 三、可塑性不等于任意可编程

既然人能适应，为什么不随便给一个解码器，让人慢慢学？

因为神经系统已有的活动组织，限制了哪些变化容易产生。

Sadtler 等人记录猕猴运动皮层的群体活动，再改变活动到光标速度的映射。在数小时的学习尺度上，动物更容易学会使用原有低维活动空间内的模式；要求产生偏离这一空间的模式，则更困难。[原论文，2014](https://www.nature.com/articles/nature13665)

可以把这里的“低维”理解为神经元之间已有的协同变化。如果两个神经元通常一起增强、一起减弱，让它们共同升高，和要求一个升高、另一个降低，不是同等容易的操作。这个二元例子只是帮助理解，实验研究的是更大的神经元群体。

这给模型设计增加了一个常被遗漏的目标：输出映射不仅要能拟合历史记录，还应让使用者容易生成需要的活动模式。数学上可表达的控制规则，未必是生物系统短时间内学得会的规则。

稳定也不意味着永远冻结。Silversmith 等人在一名瘫痪参与者的皮层脑电接口中，让解码器跨天继承参数并持续闭环适应，观察到控制与神经映射的巩固；每日重新初始化则伴随更差、且不稳定的重新学习。这项研究支持的是保留学习连续性的价值，不能直接推广成所有头皮脑电系统的最优方案。[原论文，2020 年在线发表](https://www.nature.com/articles/s41587-020-0662-5)

因此，“机器一直追着人更新”和“机器完全不动”都不是普遍答案。真正要保护的，是人已经学会的控制关系，同时允许系统补偿确实发生的变化。

## 四、反馈是否有用，要在回路里判断

书中把实时反馈放在康复流程末端。但从系统角度看，它同时也是下一轮输入的起点。

这使延迟成为学习条件的一部分。模型推理只花几毫秒，不等于反馈只延迟几毫秒：采集窗口、滤波、通信和设备响应都在链路上。若某项特征需要观察一段时间，换更快的显卡也不能直接免掉这段证据积累。

例如，首次判断要求收齐一个半秒窗口，就不能在采集开始后 5 毫秒完成。之后可以滚动更新，更新间隔也可以远短于半秒，但每个输出仍汇集了一段过去的信息。窗口长度、更新频率和实际响应延迟是三个不同的量。

评价时也应把问题分开：固定解码器，观察使用者能否逐步学会；再允许模型更新，检查额外收益；最后看隔天回来能否保持，以及为此付出了多少校准时间。还应记录到达目标的时间、轨迹与失败次数，而不只报告片段分类准确率。

若设备自动把光标吸向目标，成功率当然可能上升，却还需要区分人的控制改善和辅助算法替人完成了多少。控制表现的提高，也不能直接替代脱离设备后的功能评估。

回到视觉，这条线索比“给 CNN 多加几条反馈连接”更具体：**系统的输出，会改变下一次获得的信息。** 对一张固定照片分类时，图片不会回应模型；人在观察、操作和修正时，输入却始终受行动影响。脑机接口把这种差别变成了可以操纵映射、观察适应的实验。

下一篇再往前走一天：人已经学会了，模型也保存了，可第二天戴上设备，为什么仍可能失效？
