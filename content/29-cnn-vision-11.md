# 看不清时视觉系统怎样重新检查证据

*CNN 与生物视觉 · 第十一篇*

透过栅栏看一辆自行车，第一眼可能只看到几段弧线。再看一会儿，车轮与车架的关系逐渐明确。但画面并没有因此多露出一块。

上一篇讨论移动眼睛获取新信息。这一篇先把输入固定，问另一件事：同一份证据，多处理几轮，为什么可能得到更好的解释？

答案取决于后面的计算能否改变前面的判断。如果只是反复输出同一个类别，次数再多也没有收益。

## 一、较晚出现的答案提供了什么证据

Tang 等人让观察者识别部分可见的物体，并结合行为、神经记录和模型比较。部分图像的识别会受到随后出现的掩蔽刺激明显影响；相关选择性神经响应也比完整物体更晚出现。加入循环连接的模型能够改善他们测试中的模式补全。[原论文，2018](https://doi.org/10.1073/pnas.1719397115)

这里值得关注的不是“人比模型强”，而是同一任务的答案需要多少处理时间，以及中途干扰会破坏什么。

但响应较晚，本身并不能单独证明反馈。更长的前馈链也要时间，掩蔽也不是一把只切断反馈的手术刀。实验需要把行为时序、神经响应和计算模型放在一起约束解释。

Kar 等人在猕猴下颞叶记录中也发现，某些挑战图像的可用物体信息较晚形成。更深的前馈网络和较浅的循环网络，都能更好地预测部分晚期响应。[原论文，2019](https://doi.org/10.1038/s41593-019-0392-5)

因此，需要解释的是额外计算的功能，而不能把“晚一点”直接翻译成某一种网络结构。

## 二、同一块空白可以有两种含义

看一条被挡住的线：

```text
可见片段       遮挡       可见片段
────────       ███       ────────
```

如果中间确实是遮挡物，那里没有线的观测，并不等于线不存在；如果中间是清晰可见的背景，空白就可能是线已断开的证据。

二者在一个粗糙的特征图里，都可能表现为“中间没有检测到线”。但解释完全不同：一种是缺少证据，另一种是存在反证。

这提供了反馈可能参与的具体工作。较大范围的处理先提出“这里有一个遮挡物”的解释，再影响局部如何使用空白区域：降低被遮挡区域作为反证的权重，检查两侧轮廓是否能接续。反过来，局部出现的不相容细节，也应该削弱整体猜测。

可以用三个数写出一个简化补全问题。左右位置都观察到 1，中间未知，记为 `u`。若暂时采用“相邻位置应连续”的假设，选择使下式最小的值：

```text
代价 = (u − 1)² + (1 − u)²
```

答案是 `u = 1`。可如果中间明确观察到 0，就应当加入与观测一致的约束：

```text
代价 = λ(u − 0)² + (u − 1)² + (1 − u)²
```

这时答案变为 `u = 2 / (λ + 2)`。观测越可靠，λ 越大，补全结果就越接近 0。不能因为两边像一条线，就把中间清楚的空白强行填满。

这个玩具模型没有证明大脑在求解这条公式。它把一个设计要求说清了：整体一致性可以帮助解释缺失信息，但应当受到实际观测的约束。

## 三、循环与加深各自买到了什么

一个循环单元可以写成：

```text
新状态 = F(当前状态, 图像证据)
```

每一轮利用已有解释和输入证据，产生下一轮状态。轮廓之间的支持、候选类别之间的竞争，都可以随迭代逐步传播。

若运行次数固定，把这个单元展开，就是多层使用同一组参数的前馈计算图。因此，“循环能做到而任何前馈网络绝对做不到”通常不是正确的比较方式。

更实际的取舍在于参数、计算时间和灵活性。重复使用一个单元可以共享参数，但不会免掉每轮运算；给困难图像更多轮次，可以分配额外计算，却也需要可靠的停止条件。一次性很深的网络则可以使用不同层的参数，承担不同步骤，但不一定会为简单图像自动少算一些。

反馈是循环连接的一种情形：较高层的状态返回影响较低层处理。横向连接也能形成循环。两者都不等于眼睛移向另一处，更不等于训练阶段更新权重。

| 改变方式 | 本次处理增加了什么 |
| --- | --- |
| 转动眼睛重新观察 | 新的感官取样 |
| 固定输入，多轮更新状态 | 对已有证据的进一步计算 |
| 用样本训练网络 | 供以后使用的参数变化 |

把三件事分开，就不会把所有“再看一次”都画成同一条箭头。

## 四、更多轮次也可能放大错误

如果模型把自己刚刚猜出的轮廓，当作新获得的独立证据，再用它支持同一个类别，信心就可能越来越强，输入却没有提供更多支持。

这与真正的证据整合不同。同一条观测绕回一圈，不会自动变成第二条独立观测。循环模型需要保留输入约束，也需要允许候选解释被推翻。

评价它时，可以设计成对图像：一张是线被遮挡，另一张是线真的断开。好的补全应帮助前者，同时避免把后者也修成连续。若只考查“补得像不像”，就会奖励过度补全。

模型比较还需要控制训练数据、参数量和计算量。给循环模型更多运算，再与浅层网络比较，只能说明额外计算有用，不能独立说明循环形式不可替代。把迭代中间的预测保存下来，也比只报告最终准确率更有解释力：它是在逐步排除错误，还是先猜对再被后续计算带偏？

对于人类实验，则可以进一步改变刺激呈现和干扰的时刻，检查哪些信息先形成、哪些判断更依赖后续处理。时间在这里不仅是速度指标，也是区分计算过程的实验变量。

回到电影，遮挡、剪辑与复杂背景会不断制造不完整证据。更长的处理可能帮助识别，却不能保证把从未显示的内容还原成事实。视觉系统需要给出一个可用解释，而我们在分析它时，还必须分清“解释成立”和“细节确实被看见”。

下一篇就从这条边界出发：看见的细节，哪些来自画面，哪些来自先验？
