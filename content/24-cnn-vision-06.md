# 脑电降噪怎样改变我们看到的证据

*CNN 与生物视觉 · 第六篇*

一段脑电，处理前毛刺很多，处理后平滑整齐。我们很容易觉得，后者离真实的大脑更近。

但“更像一条好看的波形”和“更忠实地保留了答案”，没有必然联系。降噪既可能删掉有用变化，也可能制造新的波峰。问题不只是滤波强度，而是处理过程凭什么区分信号与干扰。

《Brain-to-Computer Interfaces Using Machine Learning and Deep Learning》第三章介绍滤波与独立成分分析，第五章介绍自编码器。顺着这条线追下去，最值得问的是：**我们究竟想恢复完整波形，还是保住某个问题的证据？**

## 一、滤波器不知道什么是噪声

低通保留较慢的变化，高通压低较慢的变化。这里的“慢”和“快”描述频率，不描述价值。如果目标活动和干扰占据同一频段，单靠频率选择，就不能把它们干净地分开。

更容易忽略的是，滤波会重新分配变化在时间上的形状。

看一个能手算的例子：把当前点及前后两点求平均，再从当前值中减去这个平均。它会消除常量，保留相对邻域的变化，是一个简化的高通操作。

```text
输出[t] = 输入[t] − (输入[t−1] + 输入[t] + 输入[t+1]) / 3
```

让原始信号在三个采样点上升到 1，其余为 0，窗口外也补 0：

```text
原始：  0    0     0     1    1     1     0    0    0
处理：  0    0   −1/3   1/3   0    1/3  −1/3  0    0
```

一个正向平台，变成了两端正、外侧负的结构。原本没有的负向偏转出现了，甚至提前一个采样点出现。

这不是大脑提前反应了。我们的公式用到了下一个采样点，未来的上升进入了当前点的平均值。这样的居中计算可以离线完成；实时使用则需要等待未来数据，承担延迟。实际滤波器的形状更复杂，但“输出时间结构取决于滤波规则”这件事没有变。

Tanner 等人在事件相关电位研究中展示过，不合适的高通设置能引入人为成分，影响对认知过程的解释。上面的数字是原理演示，不是复现他们的实验，也不提供通用截止频率。[原论文，2015](https://doi.org/10.1111/psyp.12437)

读一张脑电图时，波峰出现在哪里、朝哪个方向，既包含被测活动的信息，也包含测量与处理系统的影响。

## 二、分出了成分，谁来决定删哪一个

频率分不开时，可以利用多个电极的差异。独立成分分析，也就是 ICA，尝试在混合记录中分解出统计上独立的成分。

它解决的是分解问题。把某个成分命名为“眨眼”，再决定将它移除，是后续的判断。统计独立性本身不会给成分贴上生理标签；当分解不完全时，一个成分还可能混有不同来源的活动。

Plöchl 等人同时记录脑电与眼动，用眼动仪给出的扫视时段辅助识别眼动相关成分。这比仅凭波形“长得像伪迹”多了一份外部证据。他们也讨论了某些眼动伪迹难以被 ICA 单独分离的情况。[原论文，2012](https://www.frontiersin.org/journals/human-neuroscience/articles/10.3389/fnhum.2012.00278/full)

这里有一个与生物视觉直接相关的区别：眼球运动对视觉行为很重要，但它产生在头皮记录中的电位，不一定是我们想研究的皮层活动。

假设一项实验要求人向左或向右看。分类器仅靠眼动电位，也可能猜中指令。若目标是做一个眼动控制器，这条信息有用；若目标是证明模型读到了运动前的脑内意图，同样的准确率就不够。

因此，“它来自身体”不能证明应当保留，“删掉后准确率下降”也不能证明删错了。必须先明确：希望系统依据什么完成任务，以及结论准备解释到哪一层。

## 三、误差降了十八倍，答案却没了

第五章的自编码器把问题推进了一步：不用手工决定每个频段，而是让网络压缩输入，再重建输入。

但普通自编码器若以带噪输入作为重建目标，并没有天然理由只复原其中的神经活动。去噪自编码器则明确训练模型从人为扰动后的输入恢复目标样本；Vincent 等人的工作证明了这种训练可以帮助学习有用表示。它的有效性仍依赖扰动方式、目标数据和实际任务的关系。[原论文，2010](https://www.jmlr.org/papers/v11/vincent10a.html)

即使真的有干净目标，平均重建误差也不是任务信息的完整度量。

设想两类等概率出现的信号，各只有三个数。类别由最后一个数的正负决定。干扰只加在前两个数上：

| 状态 | A 类 | B 类 |
| --- | --- | --- |
| 干净目标 | (10, 10, 1) | (10, 10, −1) |
| 带噪输入 | (13, 7, 1) | (13, 7, −1) |
| 某个处理器的输出 | (10, 10, 0) | (10, 10, 0) |

这个处理器把前两个数平均，并把第三个数置零。它成功消除了大的扰动，也抹掉了小的类别差异。

处理前，相对干净目标的均方误差是：

```text
(3² + (−3)² + 0²) / 3 = 6
```

处理后，误差只有 `1/3`，降低了十八倍。但原来读取末位就能区分两类，现在两个输出完全相同。在两类等概率、没有其他输入的设定下，任何分类器的最佳准确率都只有 50%。

这是人为构造的反例，不是某个去噪网络的实测成绩。它说明了一个足够一般的问题：**误差按数值大小计分，任务可能靠一个很小的差异作答。** 更低的重建误差，不能单独保证更好的任务表现。

一旦两个不同状态被处理成完全相同的输入，后面的 CNN 再深，也无从辨别这一次原来是哪一个。它可以根据训练经验猜测，却不能把猜测当作本次测量保留下来的证据。

## 四、有效降噪需要什么证据

这并不意味着最好什么都不处理。有限的数据和模型很容易被强干扰牵着走，适当处理能让有用规律更容易学到。取舍在于：减少干扰带来的收益，是否超过删掉线索和改变波形的损失。

因此，验证需要同时照顾波形与任务。

有已知干净信号时，可以叠加可控干扰，检查处理后是否保住目标的幅度、时序或频段特征。只有真实记录时，可以借助眼动、肌电等参考记录核对干扰来源，但不能把另一条也有噪声的记录当作绝对真值。

任务评估则要比较原始数据、温和处理与较强处理，并让各自的模型在对应输入上训练，再到独立测试数据上比较。否则，把滤过的数据直接交给只见过原始数据的模型，性能下降可能只是输入分布变了。处理参数也应在训练与验证阶段确定，避免反复查看测试答案来挑方案。

最后还需要改变干扰与标签之间的关系。例如上面的左右眼动实验，可以改变注视要求，检查模型是否仍能利用目标脑活动完成任务。一次随机划分中的高分，未必能发现它一直在借用眼动线索。

回到电影院，如果要研究不同放映条件下的视觉反应，观众的眨眼与眼动既可能污染脑电，也可能是值得单独研究的行为。更合理的做法是分别测量、分别提出问题，而不是把一切整理成一条“干净曲线”，再期待它回答全部问题。

前几篇问的是视觉系统该丢掉什么。这一篇多了一条约束：**丢弃之前，要知道用什么证据确认答案还在。**
