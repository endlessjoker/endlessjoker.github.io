# CNN 学会读脑电以后知道了什么

CNN 与生物视觉 · 第四篇

如果给观众戴上脑电帽，用 CNN 判断他正在看 2D 还是 3D，模型猜对了，说明什么？

它可能捕捉到了与双眼视觉有关的信号，也可能利用了亮度差异、眨眼或眼部肌肉活动。准确率回答了“能不能区分这批记录”，还没有回答“凭什么区分”。

《Brain-to-Computer Interfaces Using Machine Learning and Deep Learning》中，有两组内容值得放在一起读：第 3 章的信号采集与预处理，以及第 5 章按信号类型选择网络结构的讨论。[1] 它们把前三篇的设计问题带到了一个更具体的地方：**输入虽然也排成矩阵，矩阵的两条轴却未必应该受到相同对待。**

## 脑电不是大脑的像素图

头皮 EEG 测的是电极相对于参考的电位差。不同来源的电活动经过头部组织传导，在测量位置叠加；眼动、肌肉和设备也可能贡献信号。一个电极不是一个神经元，也不能直接当成它下方某块皮层的独立读数。[2](https://buzsakilab.com/content/PDFs/BuzsakiKoch2012.pdf)

可以先用一个简化关系理解这个困难：

```text
测量 X = 混合关系 A × 神经源活动 S + 干扰 N
```

模型拿到的是 X，研究者真正想解释的可能是 S。由 X 预测一个标签，不要求把 A、S、N 都唯一解出来。

书中关于 EEG、ECoG 和 fMRI 的区分，最有用的也在这里：选择采集方式，已经决定了接下来能看到什么。[1，§3.3] 增加网络深度不能自动补回仪器没有测到的信息。

因此，预处理不是单纯让曲线更好看。去除哪些频率、如何处理眼动、采用什么参考，都会改变模型能利用的线索。是否应该去掉某种成分，取决于想完成控制任务，还是想解释某种脑过程。

## 时间可以平移电极不能随便换位置

假设一段 EEG 有 64 个电极，每个电极记录 256 个时间点，输入就是 64 × 256 的矩阵。它看起来像灰度图，但两条轴的含义不同。

沿时间移动一个小波形，通常仍是同一种波形，只是出现时间变了；把一行换到另一行，则可能把额部电极换成枕部电极。相邻行是否对应头皮上的邻居，还取决于电极怎样排序。

直接套一个在两条轴上滑动的图像卷积核，等于先作出了很强的假设：这些位置变化可以共用规则。这个假设应由测量布局和任务来解释，不能由“数据是二维的”来决定。

书中提到的 EEGNet 给了一个具体方案。它先沿时间学习滤波器，再针对每个时间滤波器，学习跨越全部电极的空间加权；后续再汇总时间特征、组合特征图。[3，图 1、表 2](https://arxiv.org/html/1611.08024v4)

```text
各电极的时间序列
    ↓ 同一时间滤波器应用于各电极
不同时间尺度或频率特征的响应
    ↓ 针对各类响应，学习跨电极组合
供后续分类使用的特征
```

前一步复用“怎样识别这个波形”，后一步学习“这些电极怎样组合才有用”。空间滤波器覆盖电极轴，而不是把额部学到的局部模板沿电极列表一路滑到枕部。

这种分解也付出了限制：在这两步的线性部分，一个分支对“电极 × 时间”的有效权重具有可分离结构，不能任意指定每个电极在每个时间偏移上的独立权重。它用结构限制换取较少的参数，再用多个分支增加表达能力。

这正是第二篇参数共享问题的延伸：**共享的依据来自坐标的意义，而不是矩阵的形状。**

## 一个没有目标信号的通道为什么能很重要

现在看一个只有两条记录的人工例子。s 是要恢复的目标信号，n 是与 s 独立的共同干扰：

```text
电极 1：x₁ = s + n
电极 2：x₂ = n
```

用下面的解码器，就能精确恢复 s：

```text
预测 ŝ = x₁ − x₂ = s
权重 w = [1, −1]
```

| 目标 s | 干扰 n | 电极 1 | 电极 2 | 预测 ŝ |
| ---: | ---: | ---: | ---: | ---: |
| 1 | 2 | 3 | 2 | 1 |
| 1 | −2 | −1 | −2 | 1 |
| −1 | 2 | 1 | 2 | −1 |
| −1 | −2 | −3 | −2 | −1 |

第二个电极完全没有目标信号，但它的权重绝对值与第一个一样大。删除它，预测还会变差。

如果把大权重直接涂成“负责这个功能的脑区”，就会把一个用于消除干扰的通道误判成信号来源。负权重也不等于大脑中的抑制性作用。

Haufe 等系统讨论过这种问题：从观测预测目标的解码权重，不能直接按信号来源解释；在线性情形下，需要结合数据协方差，把解码滤波器转换为相应的前向模式。[4](https://pubmed.ncbi.nlm.nih.gov/24239590/)

这个小例子甚至不用复杂方法就能看清：跨表中四种等概率情况，电极 1 与 s 的协方差为 1，电极 2 与 s 的协方差为 0。它们与目标的关系，和权重 [1, −1] 展示的关系不同。

CNN 可以从更多通道和更复杂的组合中消除干扰，但非线性不会自动消除解释上的陷阱。预测时需要一个输入，不等于那个输入就是目标过程的发生地点。

## 换一个人还能读出来吗

评估方式还决定了“会读脑电”的适用范围。

要预测同一个人的新试次，可以在这个人的数据内设计训练与测试；要交给一个从未见过的观众使用，就需要按人留出测试。来自同一次试次、尤其相互重叠的片段，也不应混进两边，让模型在测试时重见训练中的内容。

EEGNet 原论文分别评估了被试内和跨被试的表现。[3] 这是两个问题，不应把前一个问题的结果包装成后一个问题的能力。

回到影院，假设我们真要研究 3D 引起的观看不适，就需要先决定标签是什么。影片格式、观众报告的不适程度、视功能检查结果，是三种不同的标签。能识别格式，不能自动升级成能测量疲劳，更不能升级成发现了眼组织损伤。

一个可检验的研究方案，可以让同一批观众观看匹配的 2D、3D 内容，控制亮度和顺序，记录眼动与不适报告，再检验模型在新观众上是否仍有预测力。如果只有去掉眼动信息前有效，也不能立刻宣布失败：它说明我们需要重新辨认预测依赖的信号。

这本脑机接口书带来的价值，是把“模型像不像大脑”换成了一个可以操作的问题：**模型究竟在处理哪种测量，依靠什么线索，结论能走到哪一步？**

下一篇回到视觉层级。看过脑电解码的例子以后，我们再检查“CNN 学会了识别物体”这句话：它认出的究竟是物体形状，还是一组足够好用的纹理线索？
