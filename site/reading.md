# 从这里开始

这组笔记适合已经写过简单 SwiftUI 页面、希望理解状态和并发行为的读者。

这组笔记从个人项目 epubBooks 写起。它目前是一个 macOS Markdown 阅读器：把不同位置的文件放在同一个侧栏里，点开就读。窗口和菜单怎么共用数据，文件怎样加载，关掉页面后谁还留着对象，都可以顺着实际代码慢慢看。

## 阅读方法

可以从第一篇开始，也可以直接挑一个最近遇到的问题。文章会从看起来没毛病的代码讲起，看看它在哪一步出了岔子，再慢慢改。

代码都放在解释旁边，不用先下载工程、跑一组脚本才能接着读。看到某一行觉得不对劲，停下来琢磨一下，往往比急着看完更有意思。

## 想自己写写看

第一篇使用 macOS 的窗口和菜单 API，以及 @Observable、@State、@Bindable。Observation 在 SwiftUI 中需要 macOS 14 或更新系统；阅读器当前工程的最低系统版本以工程配置为准。

文章里的模型显式标记了 @MainActor。Xcode 的 Swift 语言模式和默认隔离设置会影响并发诊断；遇到不同提示时，把这些设置和编译器版本一起看，别急着怀疑自己抄错了。
