# 关于这组笔记

这里记录 Swift 和 SwiftUI 的实用学习过程。作者：**endlessjoker**。

起因是想舒服地读 AI 写的教材，后来索性开始写自己的阅读器 epubBooks。这里沿着这个个人项目，记下 SwiftUI 界面、文件读取、状态管理和异步代码中的问题。讲解时会节选项目代码，也会用单独的小例子把问题缩小。

文章从一个小功能写起，记下当时怎么想、代码为什么这么写，还有哪些地方没弄明白。以后回来翻，也能知道自己当时在折腾什么。

网站按北京时间每天上午 9 点发布一篇经过检查的备稿。定时服务可能稍有延迟；没有通过检查的备稿时，保持现有内容。

文章和补充代码保存在 [GitHub 仓库](https://github.com/endlessjoker/endlessjoker.github.io)。读正文不需要先下载代码。仓库中的待发布稿也是公开的，网站按日期连载。

发现问题时，可以在 GitHub 提交 Issue，附上章节、运行环境、复现步骤和实际结果。技术性更正会更新原文。
